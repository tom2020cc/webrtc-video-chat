## 现场问题

1. npm 默认源错误，指向 `https://cdn.npmmirror.com/binaries/npm/`，安装 cors 返回 404。仅给本次命令指定官方 registry，生产依赖安装成功。
2. HTTP 标准端口时前端省略 PeerJS port，库默认使用 443，浏览器持续 network 错误。显式设置 HTTP=80、HTTPS=443，并保留自定义端口后恢复。
3. 宝塔终端无障碍文字不包含输出，且控制延迟较高。通过真实截图核对每一步是否执行，避免重复部署。
4. 首次服务健康检查早于 Node 完成监听，脚本重试后成功，服务 active + enabled。

## 运维

```bash
systemctl status webrtc-video --no-pager
journalctl -u webrtc-video -n 50 --no-pager
systemctl restart webrtc-video
curl -I http://127.0.0.1:3100/
nginx -t
```

初装脚本 `deploy/install-isolated.sh` 对已存在用户、服务或配置会停止，不要重复执行。后续更新只替换本视频项目所需文件，再重启本服务；前端静态文件更新无需重启。
