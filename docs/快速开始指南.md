# WebRTC 本地测试快速开始指南

## 🚀 30秒快速开始

### 1. 启动服务器
```bash
npm start
```

### 2. 电脑端访问
打开浏览器访问：`http://localhost:3000`

### 3. 手机端访问
1. 确保手机和电脑在同一 WiFi
2. 获取电脑 IP：在 CMD 运行 `ipconfig`
3. 手机浏览器访问：`http://你的IP:3000` (例如：`http://192.168.31.155:3000`)

### 4. 开始测试
- **电脑端**：创建房间 "test123"
- **手机端**：加入房间 "test123"
- 开始视频通话！

## 🔧 常见问题

### ❌ 手机无法访问
1. 检查是否同一 WiFi
2. 确认服务器已启动
3. 检查防火墙设置

### ❌ 无法获取摄像头权限
1. 检查浏览器权限设置
2. 检查手机系统设置
3. 尝试其他浏览器

### ❌ 看不到对方画面
1. 确认同一房间号
2. 检查双方都开启摄像头
3. 刷新页面重试
