## 🔨 安装问题

### Node.js 版本不兼容

**问题**：
```
Error: Node.js version too old. Please use Node.js 14.0.0 or higher.
```

**解决方案**：
1. 检查当前版本：`node -v`
2. 升级 Node.js：
   - **Windows**：从 [nodejs.org](https://nodejs.org/) 下载最新版本
   - **macOS**：`brew upgrade node`
   - **Linux (Ubuntu/Debian)**：
     ```bash
     sudo apt update
     sudo apt install nodejs npm
     ```

### npm 安装失败

**问题**：
```
npm ERR! network request failed
npm ERR! code E404
```

**解决方案**：
1. **检查网络连接**
2. **清除 npm 缓存**：
   ```bash
   npm cache clean --force
   ```
3. **更换 npm 镜像源**：
   ```bash
   npm config set registry https://registry.npmmirror.com
   ```
4. **使用管理员权限**（Windows）：
   ```bash
   # 以管理员身份运行命令提示符
   npm install
   ```

### 权限问题

**问题**：
```
Error: EACCES: permission denied
```

**解决方案**：
1. **Linux/macOS**：
   ```bash
   sudo npm install
   ```
2. **修复 npm 权限**：
   ```bash
   mkdir -p ~/.npm
   chown -R $(whoami) ~/.npm
   ```

## 🚀 启动问题

### 端口已被占用

**问题**：
```
Error: listen EADDRINUSE: address already in use :::3000
```

**解决方案**：
1. **查找占用进程**：
   ```bash
   # Windows
   netstat -ano | findstr :3000

   # macOS/Linux
   lsof -i :3000
   ```
2. **终止占用进程**：
   ```bash
   # Windows (假设 PID 为 1234)
   taskkill /PID 1234 /F

   # macOS/Linux
   kill -9 1234
   ```
3. **更改端口**：修改 `server/app.js` 中的端口号

### 缺少依赖文件

**问题**：
```
Error: Cannot find module 'express'
```

**解决方案**：
1. **重新安装依赖**：
   ```bash
   npm install
   ```
2. **检查 package.json**：
   ```bash
   cat package.json
   ```
3. **删除 node_modules 重新安装**：
   ```bash
   rm -rf node_modules
   npm install
   ```

## 🎯 功能问题

### 摄像头/麦克风无法访问

**问题**：浏览器不显示摄像头画面，或无法识别语音

**解决方案**：
1. **检查浏览器权限**：
   - Chrome：地址栏左侧点击锁图标 → 允许摄像头/麦克风
   - Edge：设置 → 隐私和服务 → 媒体权限
2. **检查系统权限**：
   - **Windows**：设置 → 隐私 → 相机/麦克风
   - **macOS**：系统偏好设置 → 安全性与隐私 → 隐私
3. **测试硬件**：
   - 检查其他应用是否能使用摄像头/麦克风
   - 尝试重新插拔USB设备

### 字幕功能不工作

**问题**：点击字幕按钮后没有反应

**解决方案**：
1. **检查浏览器兼容性**：
   - 必须使用 Chrome 或 Edge 浏览器
   - 检查浏览器版本是否过旧
2. **验证 AI 配置**：
   - 确保已勾选"启用AI功能"
   - 检查语音识别引擎设置
3. **检查控制台错误**：
   - 按 F12 打开开发者工具
   - 查看 Console 标签页的错误信息
4. **重新启动字幕**：
   - 关闭字幕功能
   - 刷新页面
   - 重新开启字幕

### 翻译功能失败

**问题**：字幕显示正常，但翻译部分显示错误或空白

**解决方案**：
1. **检查 API 密钥**：
   - 验证密钥格式是否正确
   - 确认密钥未过期
2. **检查网络连接**：
   - 翻译服务需要稳定的网络连接
   - 尝试访问翻译服务官网测试连接
3. **检查配额限制**：
   - 某些 API 有调用次数限制
   - 检查账户余额和配额
4. **尝试备用翻译服务**：
   - 系统会自动尝试备用服务
   - 可以手动切换到其他翻译服务

### 视频通话质量问题

**问题**：视频卡顿、延迟或画质差

**解决方案**：
1. **检查网络带宽**：
   - 建议至少 5 Mbps 上传速度
   - 关闭其他网络应用
2. **调整视频质量**：
   - 在浏览器地址栏输入：`chrome://flags/#enable-low-end-ipc-mode`
   - 启用低延迟模式
3. **关闭其他标签页**：
   - 释放系统资源
4. **使用有线连接**：
   - WiFi 可能不稳定

## 🌐 网络问题

### 局域网无法访问

**问题**：其他设备无法访问 `http://your-ip:3000`

**解决方案**：
1. **检查防火墙设置**：
   - **Windows**：控制面板 → 防火墙 → 允许应用通过防火墙
   - **macOS**：系统偏好设置 → 安全性与隐私 → 防火墙
2. **查看本机 IP 地址**：
   ```bash
   # Windows
   ipconfig

   # macOS/Linux
   ifconfig
   ```
3. **确保设备在同一网络**：
   - 连接同一 WiFi
   - 检查路由器设置

### WebSocket 连接失败

**问题**：页面显示但功能不正常，控制台显示 WebSocket 错误

**解决方案**：
1. **检查 Socket.IO 版本兼容性**：
   ```bash
   npm list socket.io
   ```
2. **重启服务器**：
   ```bash
   # Ctrl+C 停止服务器
   npm start
   ```
3. **清除浏览器缓存**：
   - Ctrl+Shift+Delete 清除缓存
   - 或使用无痕模式测试

## 🌍 浏览器兼容性

### 推荐浏览器

- ✅ **Chrome** >= 90：完全兼容
- ✅ **Edge** >= 90：完全兼容
- ⚠️ **Firefox** >= 88：基本兼容，部分功能受限
- ⚠️ **Safari** >= 14：基本兼容，部分功能受限

| 屏幕共享 | ✅ | ✅ | ✅ | ⚠️ |
| Web Speech API | ✅ | ✅ | ❌ | ❌ |
| 文件传输 | ✅ | ✅ | ✅ | ✅ |
| 字幕历史 | ✅ | ✅ | ✅ | ✅ |

### Safari 特殊问题

**问题**：某些功能在 Safari 中不工作

**解决方案**：
1. **使用 Chrome 或 Edge** 替代
2. **启用实验性功能**：
   - Safari → 偏好设置 → 高级
   - 启用"在菜单栏中显示开发菜单"

## 📊 性能问题

### 内存占用过高

**问题**：浏览器或服务器内存占用持续增长

**解决方案**：
1. **清理聊天历史**：
   - 定期清理聊天记录
   - 设置消息数量限制
2. **重启浏览器**：
   - 关闭不需要的标签页
3. **优化视频质量**：
   - 降低视频分辨率
   - 限制参与者数量

### CPU 占用过高

**问题**：电脑风扇转动很快，CPU 占用高

**解决方案**：
1. **减少视频流**：
   - 暂时关闭不需要的视频
   - 使用屏幕共享时关闭摄像头
2. **检查后台应用**：
   - 关闭其他占用 CPU 的程序
3. **降低视频质量**：
   - 在设置中调整视频参数

## 🛠️ 调试技巧

### 启用详细日志

**修改 `server/app.js`**：
```javascript
// 在文件开头添加
const DEBUG = true;

// 替换 console.log
if (DEBUG) {
    console.log = function(...args) {
        const timestamp = new Date().toISOString();
        console.log(`[${timestamp}]`, ...args);
    };
}
```

### 检查网络请求

1. **打开开发者工具**（F12）
2. **切换到 Network 标签**
3. **筛选 WebSocket 消息**：
   - 在筛选框中输入：`socket.io`

### 检查系统资源

**Windows**：
```bash
# 任务管理器
taskmgr

# 资源监视器
resmon
```

**macOS**：
```bash
# 活动监视器
open /Applications/Utilities/Activity\ Monitor.app
```

## 📞 获取帮助

如果以上解决方案都无法解决您的问题：

1. **查看详细日志**：
   - 浏览器控制台（F12 → Console）
   - 服务器终端输出
2. **收集系统信息**：
   - 操作系统版本
   - 浏览器版本
   - Node.js 版本
3. **描述问题步骤**：
   - 重现问题的详细步骤
   - 预期结果 vs 实际结果
4. **提交 Issue**：
   - 访问项目 GitHub 页面
   - 提交详细的 Bug 报告

**💡 提示**：大多数问题都可以通过更新浏览器、重新安装依赖、或检查权限设置来解决。
