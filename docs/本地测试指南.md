# 本地测试指南

## 📋 测试环境要求

### 必需设备
- ✅ **电脑**：有摄像头和麦克风的Windows电脑
- ✅ **浏览器**：推荐使用Chrome或Edge（支持Web Speech API）
- ✅ **网络**：需要网络连接（即使是本地测试）

### 软件要求
- ✅ **Node.js**：确保已安装（用于运行服务器）
- ✅ **代码编辑器**：如VS Code（可选，用于查看代码）

## 🚀 快速开始测试

### 1. 启动服务器

```bash
# 在项目根目录打开命令行
cd "D:\Claude Demo\up_webrtc_socketio"

# 安装依赖（如果还没安装）
npm install

# 启动服务器
node server/app.js
```

看到以下提示表示启动成功：
```
服务器启动，监听端口 3000
```

### 2. 打开浏览器测试

1. **打开浏览器**（推荐Chrome或Edge）
2. **访问地址**：`http://localhost:3000`
3. **允许权限**：浏览器会请求摄像头和麦克风权限，点击"允许"

## 🎯 功能测试步骤

### 基础功能测试

#### 1. 设置用户信息
- 点击右上角的 ⚙️ 设置按钮
- 设置您的昵称
- 点击"保存并重启"

#### 2. 创建测试房间
- 在房间输入框中输入房间号（如：123）
- 点击"＋ 创建房间"
- 允许浏览器访问摄像头和麦克风

#### 3. 测试视频通话
- 检查是否能看到自己的视频画面
- 测试麦克风：点击底部控制栏的🎙️按钮测试静音功能
- 测试摄像头：点击📷按钮测试开关摄像头

## 🤖 AI字幕功能测试

### 基础字幕测试（免费，无需API）

1. **配置AI设置**：
   - 点击⚙️设置
   - 勾选"启用AI功能"
   - 语音识别引擎：选择"🌐 浏览器内置"（免费！）
   - 翻译服务：暂时选择任意一个（字幕识别功能仍可用）
   - 点击"保存并重启"

2. **开启字幕功能**：
   - 点击底部控制栏的"📝 字幕"按钮（或按T键）
   - 开始说话，观察是否实时显示识别的文字

### 高级AI翻译测试（需要API密钥）

#### 免费测试选项：

1. **Google翻译测试**：
   - 获取Google Cloud Translation API密钥
   - 在设置中选择Google翻译
   - 输入API密钥

2. **百度翻译测试**：
   - 注册百度翻译API
   - 获取AppID和密钥
   - 在设置中输入格式：`appId:密钥`

#### 付费测试选项：

1. **OpenAI翻译**：
   - 需要OpenAI API密钥
   - 按量计费，效果较好

2. **DeepL翻译**：
   - 需要DeepL API密钥
   - 翻译质量很高

## 📝 字幕历史测试

1. **开启字幕功能**并说几句话
2. **查看历史记录**：
   - 点击聊天室旁边的📝按钮
   - 查看字幕历史列表
   - 测试搜索功能
3. **测试导出功能**：
   - 点击导出SRT/TXT/JSON按钮
   - 检查下载的文件内容

## 👥 多人测试（可选）

### 方法一：多个浏览器窗口
1. 打开两个浏览器窗口/标签页
2. 都访问 `http://localhost:3000`
3. 设置不同的昵称
4. 加入同一个房间
5. 测试视频通话和字幕同步

### 方法二：局域网测试
1. 确保两台电脑在同一WiFi网络
2. 查看服务器电脑的IP地址（如：192.168.1.100）
3. 第二台电脑访问：`http://192.168.1.100:3000`
4. 加入同一个房间进行测试

## ⚠️ 常见问题解决

### 摄像头/麦克风无法访问
```bash
# 解决方案：
1. 检查浏览器地址栏左侧的权限图标
2. 确保已允许摄像头和麦克风权限
3. 检查系统隐私设置中的摄像头权限
```

### 字幕功能不工作
```bash
# 解决方案：
1. 确保使用Chrome或Edge浏览器
2. 检查是否勾选了"启用AI功能"
3. 尝试刷新页面重新授权
4. 检查浏览器控制台是否有错误信息
```

### 翻译功能失败
```bash
# 解决方案：
1. 检查API密钥是否正确
2. 验证网络连接是否正常
3. 查看浏览器控制台的错误信息
4. 确认API服务是否需要付费
```

### 服务器启动失败
```bash
# 解决方案：
1. 检查端口3000是否被占用
2. 尝试重启电脑
3. 检查Node.js是否正确安装
```
