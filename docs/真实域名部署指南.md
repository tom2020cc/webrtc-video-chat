## 🛠️ 服务器环境搭建

### 1. 安装Node.js
```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# CentOS/RHEL
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs

# 验证安装
node -v
npm -v
```

### 2. 上传项目文件
```bash
# 方法1: 使用git
git clone <your-repo-url>
cd webrtc-video-chat

# 方法2: 使用SCP (从本地上传)
scp -r D:\Claude Demo\up_webrtc_socketio user@server:/home/user/

# 方法3: 使用FTP工具
# FileZilla, WinSCP等
```

### 3. 安装依赖
```bash
cd /path/to/webrtc-video-chat
npm install
```

### 4. 配置防火墙
> 本项目为**单端口架构**：页面、Socket.IO 信令、PeerJS 信令全部走 3000 端口（PeerJS 挂载在 `/peerjs` 路径），
> 只需开放 3000 即可，无需额外开放 9000。
```bash
# Ubuntu (UFW)
sudo ufw allow 3000/tcp

# CentOS (Firewalld)
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload

# 阿里云/腾讯云安全组
# 在控制台添加安全组规则：
# 端口: 3000
# 协议: TCP
# 来源: 0.0.0.0/0
```

### 5. 启动服务
```bash
# 测试启动
npm start

# 使用PM2守护进程 (推荐)
npm install -g pm2
pm2 start server/app.js --name webrtc-app
pm2 save
pm2 startup

# 查看日志
pm2 logs webrtc-app
pm2 status
```

## 🔒 HTTPS配置 (生产环境必须)

### 1. 使用Let's Encrypt免费证书
```bash
# 安装certbot
sudo apt-get install certbot python3-certbot-nginx

# 生成证书 (需要域名已解析)
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 证书自动续期
sudo certbot renew --dry-run
```

### 2. Nginx反向代理配置
```nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;

    # 强制HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com www.your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # 单端口架构：页面 + Socket.IO + PeerJS（/peerjs）全部走 3000，一个 location 即可
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 300s;
    }
}
```

### 3. 修改服务器代码支持HTTPS
```javascript
// server/app.js
const https = require('https');
const fs = require('fs');

const httpsOptions = {
  key: fs.readFileSync('/etc/letsencrypt/live/your-domain.com/privkey.pem'),
  cert: fs.readFileSync('/etc/letsencrypt/live/your-domain.com/fullchain.pem')
};

const httpsServer = https.createServer(httpsOptions, app);
const ioHttps = socketIo(httpsServer, {
  cors: { origin: "*", methods: ["GET", "POST"] }
});

httpsServer.listen(3001, '0.0.0.0', () => {
  console.log("HTTPS服务器启动，端口3001");
});
```

## 📱 客户端配置更新

> **同源自动适配**：客户端会根据当前页面地址自动推导 PeerJS 连接（同域名、同端口、同协议），
> 部署到域名后**通常无需手动配置**。以下预设仅作为手动兜底。

### 当前预设（client/js/i.js）
```javascript
const PRESETS = {
  local:  { env: "local",  serverUrl: "http://localhost:3000", peerHost: "localhost", peerPort: "3000", secure: false, path: "/peerjs", nickname: "" },
  prod:   { env: "prod",   serverUrl: "https://your-domain.com", peerHost: "your-domain.com", peerPort: "", secure: true, path: "/peerjs", nickname: "" },
  custom: { env: "custom", serverUrl: "http://YOUR_CUSTOM_URL", peerHost: "YOUR_HOST", peerPort: "PORT", secure: false, path: "/peerjs", nickname: "" }
};
```

### 部署到你的域名时
1. 把 `prod.serverUrl` / `prod.peerHost` 中的 `your-domain.com` 换成你的域名
2. `peerPort` 留空 = 跟随页面端口（单端口架构下推荐始终留空）
3. 旧版本配置中若残留 `peerPort: "9000"`，客户端会自动迁移为跟随页面端口，无需手动处理

## 🔧 常见问题解决

### 1. 端口被占用
```bash
# 查看端口占用
sudo netstat -tulpn | grep :3000

# 结束进程
sudo kill -9 <PID>
```

### 2. 防火墙阻止
```bash
# 临时关闭防火墙测试
sudo ufw disable

# 重新启用
sudo ufw enable
```

### 3. 域名解析未生效
```bash
# 检查DNS状态
dig your-domain.com
whois your-domain.com

# 本地hosts文件测试 (Windows)
# C:\Windows\System32\drivers\etc\hosts
# 添加: 服务器IP your-domain.com
```

### 4. HTTPS证书问题
```bash
# 检查证书状态
sudo certbot certificates

# 重新生成证书
sudo certbot certonly --standalone -d your-domain.com
```
