WebRTC 本地测试教程

手机与电脑互通测试完整指南

🎯 准备工作

1 确认网络环境

确保手机和电脑连接到同一个Wi-Fi网络

2 获取电脑IP地址

在命令提示符(CMD)中输入以下命令：

ipconfig

查找"IPv4 地址"，例如：192.168.31.155

🖥️ 本机IP
192.168.31.155
您的电脑局域网地址
📡 服务端口
3000
WebRTC服务端口
🌐 访问地址
http://192.168.31.155:3000
手机浏览器输入此地址

🚀 启动服务器

方法一：普通启动

npm start

方法二：开发模式（推荐）

npm run dev
✅ 启动成功标志：

看到控制台输出："服务器启动，监听端口 3000"

⚠️ 防火墙设置：

如果启动失败，请确保防火墙允许端口3000的入站连接

📱 手机访问设置

1 打开手机浏览器

推荐使用 Chrome、Safari 或其他现代浏览器

2 输入访问地址
http://192.168.31.155:3000
3 允许权限

浏览器会请求摄像头和麦克风权限，请点击"允许"

🎬 开始测试通话

电脑端操作：

  • 在浏览器打开 http://localhost:3000
  • 输入房间号，如"test123"
  • 点击"创建房间"按钮
  • 允许摄像头和麦克风权限

手机端操作：

  • 在浏览器访问上述地址
  • 输入相同的房间号"test123"
  • 点击"加入房间"按钮
  • 允许摄像头和麦克风权限
🎉 连接成功后：
  • 电脑和手机都能看到对方的视频画面
  • 可以听到对方的声音
  • 可以在聊天室发送文字消息
  • 可以测试屏幕共享功能

🔧 常见问题解决

❓ 手机无法访问网页？ ▼

1. 检查手机和电脑是否在同一Wi-Fi网络

2. 确认服务器已启动

3. 检查防火墙是否阻止了3000端口

4. 尝试用其他浏览器访问

❓ 无法获取摄像头/麦克风权限？ ▼

1. 检查浏览器权限设置

2. 确认手机系统设置中允许浏览器访问摄像头/麦克风

3. 尝试使用HTTPS协议（如配置了SSL证书）

4. 检查其他应用是否占用了摄像头/麦克风

❓ 视频/音频卡顿？ ▼

1. 检查网络连接质量

2. 关闭其他占用带宽的应用

3. 尝试降低视频质量

4. 重启路由器

❓ 看不到对方画面？ ▼

1. 确认双方都加入了同一个房间

2. 检查双方是否都开启了摄像头

3. 刷新页面重新连接

4. 查看浏览器控制台的错误信息

⚙️ 高级配置

服务器配置修改（如需要）：

如果需要修改服务器监听所有网络接口，编辑 server/app.js 文件：

// 原来的代码 server.listen(3000, () => { console.log("服务器启动，监听端口 3000"); }); // 修改为监听所有接口（如果需要） server.listen(3000, '0.0.0.0', () => { console.log("服务器启动，监听所有网络接口的 3000 端口"); });

环境设置：

在客户端设置面板（点击⚙️按钮）中：

  • 服务器地址：手机端设置为 http://192.168.31.155:3000
  • PeerJS服务器：与页面同源自动适配，保持默认即可（信令挂载在 /peerjs 路径，与页面共用 3000 端口）

🔒 安全提示

⚠️ 重要提醒：
  • 此配置仅用于本地测试，不要用于生产环境
  • 局域网内其他设备可能访问到您的服务器
  • 不要在公共网络环境下进行敏感通话
  • 生产环境请使用HTTPS和WSS协议
  • 配置适当的防火墙规则和访问控制
